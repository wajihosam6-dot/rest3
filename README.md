# REST — Photos & Brand Assets Repository (rest3)

مستودع الصور الرسمية وشعارات الهوية لمنتجع وشاليهات **REST**.

## محتويات المستودع

### 1. شعار الشاليه الرسمي (Chalet Logo) — مجلد 
est_logo/
- **logo.jpg** — شعار الشاليه بدقة عالية (1080x1067 JPEG).
- **logo.webp** — شعار الشاليه بصيغة WebP خفيفة وعالية الدقة.
- **logo_alt.jpg** — النسخة البديلة لشعار الشاليه (1080x1076 JPEG).
- **rand_logo.webp** / **rand_logo_alt.webp** — شعارات الهوية بصيغة WebP.
- **
est-logo-light.svg** / **
est-logo-dark.svg** — الشعار المتجهي Vector بنمط الفاتح والداكن.
- **
est-logo-horizontal-light.svg** / **

### 2. صور الشاليه الحقيقية (20 مرفق ومعلم) — مجلد public/assets/real/
يحتوي على كافة الصور الحقيقية للشاليه بصيغتي JPG و WebP المحسنة للويب:
- المجلس الكبير والواجهات التراثية
- المسابح والشلالات المائية
- الممشى والمساحات الخضراء والحديقة
- الجلسات الأرضية ومنطقة الشواء والحكاية
- الألعاب والأكواخ الخشبية للأطفال
- ركن الورود والمراجيح
- دليل المرافق واللوحات الإرشادية

### 3. صور الأقسام — مجلدات hero/, pools/, interiors/, garden/
صور عالية الجودة مخصصة لعرض الواجهات والمرافق الداخلية.
