# REST — شاليه ومنتجع ريست (موقع المعاينة)

النسخة الحية من موقع شاليه ومنتجع ريست: ملف `index.html` واحد (نسخة v10
بالتحسينات الأخيرة: خط ثمانية، ألوان بحرية ووردية، فيديوهات مفحوصة،
نص البطل ظاهر فوراً، وإصلاح التعليق عند قسم المرافق).

## هذه النسخة

- **الصور والفيديوهات من Pexels (مخزون تجريبي للمعاينة فقط)** وليست صور
  المنتجع الحقيقية — مذكور ذلك في تذييل الصفحة.
- الشعار في `public/assets/brand/` (ملفات SVG).
- لا خطوة بناء: Vercel ينشر الموقع مباشرة من `index.html`.

## استبدال صور المخزون بالصور الحقيقية

1. ارفع صور المنتجع الحقيقية إلى `public/assets/real/` والشعار إلى
   `public/assets/brand/` (عبر git من جهازك — الصور ملفات ثنائية).
2. أخبر Orion ليبني نسخة `index.html` جديدة تشير إلى الصور الحقيقية
   بدل روابط Pexels.

## ملاحظة عن الخط

خط ثمانية يُحمَّل من jsDelivr كبديل احتياطي؛ النسخة الرسمية تُنزَّل من
font.thmanyah.com وتُرفع إلى `public/assets/fonts/thmanyah/` عند توفرها.
